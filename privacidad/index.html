2. Datos tratados

A través de los formularios del sitio web podrán tratarse los siguientes datos:

  • Nombre.
  • Empresa.
  • Dirección de correo electrónico.
  • Contenido del mensaje enviado por el usuario.
  • Persona o área de Grindlane con la que el usuario desea contactar, cuando corresponda.
  • Página desde la que se realiza la solicitud.
  • Datos técnicos estrictamente necesarios para la seguridad y funcionamiento del servicio.

No solicitamos deliberadamente categorías especiales de datos personales.

Se recomienda no incluir información sensible innecesaria en el campo de mensaje.

3. Finalidades

Los datos podrán tratarse para:

  • Atender solicitudes de información.
  • Responder consultas.
  • Contactar con potenciales clientes.
  • Analizar las necesidades empresariales comunicadas.
  • Valorar posibles proyectos.
  • Preparar propuestas relacionadas con los servicios solicitados.
  • Mantener comunicaciones relacionadas con una solicitud o posible relación comercial.
  • Garantizar la seguridad y correcto funcionamiento de los formularios y sistemas asociados.

Los datos no se utilizarán para finalidades incompatibles con las indicadas.

4. Base jurídica

Cuando el usuario contacta voluntariamente con Grindlane Consulting para solicitar información o valorar un posible proyecto, el tratamiento podrá basarse en la aplicación de medidas precontractuales solicitadas por el propio interesado.

Cuando corresponda, determinados tratamientos podrán basarse en el consentimiento otorgado por el interesado.

También podrán realizarse tratamientos cuando resulte necesario para cumplir obligaciones legales aplicables a los responsables.

5. Conservación

Los datos se conservarán durante el tiempo necesario para atender la solicitud y, en su caso, gestionar la relación derivada de ella.

Cuando no llegue a iniciarse una relación contractual, los datos se eliminarán cuando hayan dejado de ser necesarios para la finalidad para la que fueron recogidos, sin perjuicio de su conservación bloqueada durante los plazos que puedan ser necesarios para atender posibles responsabilidades legales.

6. Proveedores tecnológicos y destinatarios

Grindlane Consulting utiliza proveedores tecnológicos necesarios para operar el sitio web y gestionar las comunicaciones.

Actualmente pueden intervenir, entre otros:

GitHub Pages, para el alojamiento de los archivos públicos del sitio web.

Cloudflare, para servicios de infraestructura, dominio, seguridad y procesamiento del formulario mediante Cloudflare Workers.

Resend, para la transmisión de los mensajes generados por los formularios.

Zoho, para la gestión y recepción del correo electrónico corporativo.

Estos proveedores podrán tratar determinados datos únicamente en la medida necesaria para prestar los servicios contratados y de acuerdo con las condiciones y garantías aplicables a cada servicio.

No vendemos datos personales a terceros.

Cuando la prestación de estos servicios implique tratamientos o transferencias internacionales de datos, se aplicarán las garantías exigibles conforme a la normativa de protección de datos que corresponda.

7. Derechos

El interesado podrá ejercer, cuando resulten aplicables, sus derechos de:

  • acceso;
  • rectificación;
  • supresión;
  • oposición;
  • limitación del tratamiento;
  • portabilidad;
  • retirada del consentimiento cuando el tratamiento se base en este.

Para ejercerlos puede escribir a:

contacto@grindlaneconsulting.com

La solicitud deberá permitir identificar al interesado y especificar el derecho que desea ejercer.

También podrá presentar una reclamación ante la Agencia Española de Protección de Datos si considera que sus derechos no han sido respetados.

8. Seguridad

Se aplican medidas técnicas y organizativas razonables para proteger los datos personales frente a accesos no autorizados, pérdida, alteración o divulgación indebida.

Entre otras medidas, la web utiliza transmisión cifrada mediante HTTPS, validación de formularios y mecanismos destinados a reducir envíos automatizados no deseados.

9. Decisiones automatizadas

Los formularios del sitio web no toman decisiones automatizadas con efectos jurídicos o significativamente similares sobre los usuarios.

10. Cambios en esta política

La presente Política de Privacidad podrá actualizarse como consecuencia de cambios legislativos, técnicos, organizativos o relativos a los proveedores utilizados.
